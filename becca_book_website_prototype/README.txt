# Becca Book Website — First Prototype

Open `index.html` in a browser.

Current structure:
- Home: closed book
- Fiction
- Nonfiction
- About

The website is intentionally simple so the concept can be tested before adding:
- realistic page-turn animation
- Becca's actual artwork/portrait
- real publication data
- individual publication pages
- book/page textures
- desk or other interactive objects
- mobile-specific interactions
